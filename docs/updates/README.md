# 更新说明目录

> kali-mcp 每次更新都单独生成一份说明文件，放在本目录下。

## 约定

1. **每次更新一个新文件**：不复用、不追加，一次更新对应一份独立说明。
2. **命名格式**：`YYYY-MM-DD-<概括更新内容>.md`
   - 日期为更新完成当天；
   - 内容部分用短语概括本次核心变更（中文即可），例如：
     - `2026-08-27-新增6个IPv6网络维护工具.md`
     - `2026-09-01-修复nuclei后台扫描解析.md`
3. **文件结构**（推荐）：
   - `# 标题`（日期 + 概括）
   - `### ✨ 新增`
   - `### 🔧 修复`
   - `### 📝 改动`
   - `### 🐛 实测发现`（如有线上实测发现的 bug）
   - `### ✅ 部署与验证`（部署方式、线上验证结果）
4. 提交代码时，更新说明文件与代码改动**同一提交**，保证可追溯。
