# 2026-09-01 移除代码中硬编码的用户环境信息

> 本文件是 kali-mcp 的一次更新说明，记录本次**新增了什么、修复了什么、改动了什么**。
> 命名与存放约定见 [docs/updates/README.md](README.md)。

### 背景

应用户质询（"你不会把攻击目标写死到代码里面了吧"）全仓库排查：

- **攻击目标确认未写死**：所有攻击工具 `target` 均为必填参数（`...`，无默认值）；靶机 IP 只出现在更新文档（测试留痕）与单元测试哑值（零网络调用）中。
- 但发现两处**用户特定环境信息**被写进了代码，本次一并移除：
  1. `netinfo.py` 的 `DEFAULT_SUBNET = "192.168.0.0/24"`——子网自动探测失败时的兜底值（用户自己的局域网段），探测失败时工具会**静默地扫描一个被假设的网段**；
  2. `pentest.py` `traffic_stats` 输出美化：IP 等于 `192.168.0.1` 标注"(网关)"、等于 `192.168.0.234` 标注"(Kali)"（纯显示，且 .234 已是陈旧环境残留）。

### 🐛 修复（2 处）

1. **移除硬编码兜底子网，探测失败显式报错**：`detect_subnet` 不再回退到 `192.168.0.0/24`，探测失败返回 `None`；全部 5 个调用点显式处理——`network_topology`/`snmp_topology`/`network_diff` 返回"请通过 subnet 参数显式指定网段"；`ipv6_scan` 自动模式跳过 v4 ARP 对照并加注；`detect_gateway` 无解时返回 `""`，`arpspoof_mitm`/`arpspoof_disconnect` 返回"请通过 gateway 参数显式指定网关"。
2. **移除 `traffic_stats` 的硬编码 IP 标注**：top talkers 表格不再对特定 IP 附加"(网关)"/"(Kali)"标签。

### 📝 改动

- `src/kali_mcp/netinfo.py`：删除 `DEFAULT_SUBNET`；`detect_subnet` 返回 `str | None`；`detect_gateway` 无解返回 `""`。
- `src/kali_mcp/tools.py`（2 处）、`src/kali_mcp/monitor.py`（1 处）：subnet 为 None 时返回明确错误。
- `src/kali_mcp/ipv6.py`：v4 对照降级（跳过 + 注释）。
- `src/kali_mcp/pentest.py`：删 2 行 IP 标注；2 个 arpspoof 工具加 gateway 空值检查。
- `tests/test_netinfo.py`：兜底测试改为断言 `None`/`""`，新增"探测失败返回空"1 例。

### ✅ 部署与验证

- 本地 `pytest` **250 passed**（249+1）。
- Kali 部署 5 个文件（netinfo.py `cd756996…`、pentest.py `cec36edf…` 等 md5 两边一致）→ 服务重启 active。
- 线上 `network_topology`（不传 subnet）→ 自动探测 192.168.0.0/24 正常（探测路径未受影响，兜底路径才变）。
