# 2026-09-07 — setup.sh 依赖覆盖审计（新增工具的二进制依赖补齐）

> 索引：[修复记录/README.md](README.md)

**背景：** 逐模块（tools/monitor/ipv6/pentest/vulnscan/recon/ad/msf/transfer）核对每个工具实际调用的外部二进制与 setup.sh 三个包清单的对应关系，发现 9 个依赖缺口。全部包名已在 Kali (kali-rolling arm64) 用 `apt-get install --simulate` 验证可解析。

**修复（setup.sh）：**

1. **BASE_PKGS 补 5 个包**（base 层工具常驻注册，依赖不能藏在 --tool-level 后面）：
   - `iputils-ping` — ping_host / ipv6_ping / ipv6_doctor
   - `procps` — monitor 工具读 sysctl
   - `masscan` — masscan_scan
   - `snmp` — **从 PENTEST_PKGS 移入 BASE**：`snmp_topology` 在 tools.py 属 base 层常驻工具，其 snmpwalk 依赖原来要 `--tool-level pentest` 才装，层级错配
   - `openssh-client` — transfer 工具的 scp/ssh；vuls 的 ssh shim 同样依赖
2. **ATTACK_PKGS 补 4 个包**：
   - `hping3` — ddos_attack（SYN/UDP/ICMP flood 引擎）
   - `responder` — responder_run（直接调 /usr/share/responder/Responder.py）
   - `slowloris` — ddos_attack http/mixed；**此前"Kali 无此包"的审计结论有误**（二进制未装 ≠ 包不存在，包在 kali-rolling 仓库）
   - `sslstrip` — sslstrip_run；同样在仓库中，代码里 bettercap 回退保留但不再必要
3. **无缺口的部分确认覆盖**：pentest 层（impacket 五件套/peass/ndisc6/httpx+dalfox GitHub 二进制/nuclei 模板/subfinder/dnsx 等）与 attack 层（metasploit-framework+python3-pymetasploit3+msfrpcd 自举/vuls+ssh shim+12GB DB 按需下载/aircrack-ng/crackmapexec 等）此前已覆盖，本次未动。

**验证：** `bash -n` 语法通过；55 个包全量 `apt-get install -s` 模拟安装 exit 0；702 测试全绿。
